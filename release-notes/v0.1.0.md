# Micro Note v0.1.0

First public release.

## Features

### Editor
- Markdown editing powered by [Milkdown](https://milkdown.dev/)
- Vim mode — full Vim keybindings inside the editor (`i`, `v`, `Esc`, operators, motions)
- Toggle Vim mode on or off at any time (`Cmd+Shift+V`)

### File tree
- Vim-style navigation: `j/k` to move, `l/h` to expand/collapse
- Create files and directories (`a`)
- Rename (`r`), delete (`d`), cut/copy/paste (`x/y/p`)

### Keyboard shortcuts
- `Space+E` — toggle sidebar / focus file tree
- `Cmd+N` — new file
- `Cmd+O` — open folder
- `Cmd+I` — focus editor
- `Cmd+W` — close file
- `Cmd+Shift+F` — toggle full screen
- Cheat sheet available in the sidebar (`Cmd+,`)

### Issue tracking
- Lightweight Kanban board using `.mtf` files stored alongside your notes
- Backlog / In Progress / Done columns
- Subtasks, due dates, and descriptions

### Customization
- Override keybindings via `~/.config/micro-note/config.json`

## Installation

1. Download `Micro-Note-v0.1.0.dmg`
2. Open the DMG and drag **Micro Note** to Applications
3. Launch from Applications

## Requirements

- macOS 13 or later (Apple Silicon and Intel)
